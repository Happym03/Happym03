## 📋 GRC Methodology & Lifecycle

My portfolio work follows a structured risk management lifecycle: **Identify → Assess → Treat → Monitor → Report**

| Phase | Core Activity |
| :--- | :--- |
| **Identify** | Asset discovery, threat modeling, vulnerability identification, regulatory mapping. |
| **Assess** | Likelihood & impact scoring ($5 \times 5$ matrix), control effectiveness evaluation, residual risk calculation. |
| **Treat** | Mitigation roadmap, risk transfer, risk avoidance, or formal risk acceptance. |
| **Monitor** | Remediation tracking, continuous control testing, audit observation management. |
| **Report** | Executive KPI dashboards, risk heatmaps, board committee reporting, and escalations. |
